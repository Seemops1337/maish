# Changelog

Maish restarted versioning at 0.1.0 when it forked from Velo, and does not
continue Velo's 0.4.x line. Entries are generated by release-please from
Conventional Commits.

## 0.1.0

Initial release of the fork.

### Bug Fixes

* **imap:** parenthesise multi-item FETCH data lists, so servers that follow
  RFC 3501 §6.4.5 strictly return message bodies instead of empty messages
* **db:** run transactions on a dedicated SQLite connection rather than the
  plugin's pool, which deadlocked against itself and reported
  `database is locked`
* **calendar:** route CalDAV requests through the Rust HTTP client, since DAV
  servers send no CORS headers and the webview discarded every response
* **calendar:** attach CalDAV settings to an existing account for the same
  address instead of failing on `UNIQUE constraint failed: accounts.email`

### Features

* **calendar:** probe the configured mail server host during CalDAV discovery,
  for setups where the mail domain and the server host differ
